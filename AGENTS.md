# OpenMM project instructions

## Independent review

Always use a separate reviewer agent for implementation changes in this project.
The reviewer must assess the proposed design before implementation and independently
review the final diff, relevant test results, and performance/memory claims before
commit, push, or delivery. The implementing agent must address substantive findings
and obtain the reviewer's follow-up review when those fixes change the reviewed code.
Do not describe the implementing agent's own checks as independent review.

If an independent reviewer is unavailable, explain the limitation and do not present
the change as independently reviewed or ready for delivery.
